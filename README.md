CYPX COMMUNITY BOT
Features:
Deletes links from non-admin members
Warns on first link
Removes member after second link
Exempts group admins
Welcomes new members in English + Kiswahili
Run locally
npm install
npm start
Scan the QR code using WhatsApp > Linked devices > Link a device.
Hosting note
A free sleeping host may disconnect WhatsApp. Use persistent storage for auth_info and warnings.json; do not commit either to GitHub.
